# Classic Knowledge Base

A classic knowledge base is one where you decide how your content is chunked, indexed, and searched. It can also connect to a knowledge base you already run, which Dify searches without copying the content in.

Chatbot, Text Generator, and legacy Agent apps can answer from it, as can Workflow and Chatflow apps through the Knowledge Retrieval node.

> **Tip**
>
> - To weigh it against the agent knowledge base, see [which kind to create](https://docs.dify.ai/en/cloud/use-dify/knowledge/overview#choose).
>
> - A ready-to-use classic knowledge base can be [upgraded](https://docs.dify.ai/en/cloud/use-dify/knowledge-base/upgrade-from-classic) to an agent knowledge base. External knowledge bases and ones built as a Knowledge Pipeline can't.

## Set Up {#set-up}

- **[Create a ready-to-use knowledge base](https://docs.dify.ai/en/cloud/use-dify/knowledge/create-knowledge/introduction)**: Import data, then set how it's chunked, indexed, and searched.

- **[Build a custom knowledge base](https://docs.dify.ai/en/cloud/use-dify/knowledge/knowledge-pipeline/readme)**: Design your own processing as a Knowledge Pipeline when the standard settings don't fit your content, choosing the data sources and each step that extracts, chunks, and indexes it.

- **[Connect to an external knowledge base](https://docs.dify.ai/en/cloud/use-dify/knowledge/connect-external-knowledge-base)**: Search a knowledge base you already run through its API, without moving the content into Dify.

## Test and Improve

- **[Test and validate retrieval](https://docs.dify.ai/en/cloud/use-dify/knowledge/test-retrieval)**: Try what your users will ask and see which chunks come back.

- **[Adjust knowledge base settings](https://docs.dify.ai/en/cloud/use-dify/knowledge/manage-knowledge/introduction)**: Change the embedding model and search settings, or switch the index method from Economical to High Quality.

- **[Enhance retrieval with metadata](https://docs.dify.ai/en/cloud/use-dify/knowledge/metadata)**: Label documents so searches can be narrowed to the ones that match.

## Use and Maintain

- **[Integrate into applications](https://docs.dify.ai/en/cloud/use-dify/knowledge/integrate-knowledge-within-application)**: Connect it to your apps and set how they retrieve from it.

- **[Manage content](https://docs.dify.ai/en/cloud/use-dify/knowledge/manage-knowledge/maintain-knowledge-documents)**: Add, edit, disable, or delete documents and chunks as your content changes.
